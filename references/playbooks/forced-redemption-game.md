# 强赎博弈

核验2026-10-09。规则依据与适用范围沿用所链接规则篇；以下为研究框架，不是监管规定或概率承诺。

先依据[转债条款](../rules/cb-clause-rules.md)确认已触发、董事会决定、承诺范围和四个终止时点。股价上涨与强赎导致期权价值缩短可同时存在，不能把强赎公告必然转为正股下跌。

计算转股价值=`100×正股价/转股价`，溢价率=`债价/转股价值−1`。正溢价在退出期面临压缩，负溢价也不保证利润：转股权限、隔夜股票价格、尾款和费用仍影响。比较卖债、转股后卖股、接受赎回三条路径，使用可成交价格，不用最后报价代替成交。

情景：卖债价变化；转股后正股跌5%/10%（仅假设）；未成功转股按公告赎回价；停牌或券商申报失败。余额小、机构卖出等只作风险解释，不作涨跌确定规则。优先读[强赎操作风险](../pitfalls/redemption-traps.md)。

原包的历史统计与具体收益数字未补齐原公告，发布版未将其作为已核事实。
