# 事件研究执行核验

> 许可范围：本文件涉及原包专题或提供方案的改建来源，不声明整文件 MIT。见[第三方与未明来源](../../THIRD_PARTY_NOTICES.md)。原材料未经许可的表达不纳入根许可证。

核验2026-10-09。规则依据与适用范围沿用所链接规则篇；以下为研究框架，不是监管规定或概率承诺。

按[事件规则](../rules/event-arb-rules.md)分类要约/换股/现金选择权/重组；先提取最后版本，再算价差。

1. 建身份和文件时间轴，预案、修订、实施、结果分别记录。
2. 用[条款表](../../templates/case-terms.md)核对范围、价格、资格、生效、数量与日期。
3. 核对撤回截止、股东会登记/指定反对议案、连续持有、申报时刻、实际支付。要约最后三交易日与股东会时间锁不互换。
4. 用[情景模板](../../templates/scenario-analysis.md)算收购缩水、余股折价、价格下调、税费和延迟。
5. 用[现金联动](capital-coordination.md)查交叉缴款缺口，再输出已核事实、假设和缺口。

申报量不是投资收益率，不能用“申报多30倍”推成“收益多30倍”；无原文统计不发布比例。无对冲能力、审批不定或可能调价时，不称“无风险套利”。

已补[要约结果与现金选择权执行条款](../cases/execution-terms.md)。其余原包历史统计与具体收益数字未补齐原公告，发布版未将其作为已核事实。
