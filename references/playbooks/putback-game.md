# 回售博弈

核验2026-10-09。规则依据与适用范围沿用所链接规则篇；以下为研究框架，不是监管规定或概率承诺。

按[转债条款](../rules/cb-clause-rules.md)区分低价有条件回售和募资用途变更附加回售。核计息年度、日数、年度机会、连续持有/申报要求及下修重置。

应计利息公式、起止计息日、票息和税后价从公告提取。面值加利息不保证兑付能力；市价高于回售价与买入成本高于回售价分别比较。回售期间可否交易/转股、申报能否撤回按市场与公告，不能把深市个案撤单规则推广到沪市。

公司现金紧张可能增强下修动机，也可能意味着违约/延迟。情景：正常支付；到账晚；回售未成功；下修后条件变化；公司无法支付。参考[信用风险](../pitfalls/cb-defaults.md)。

原包的历史统计与具体收益数字未补齐原公告，发布版未将其作为已核事实。
