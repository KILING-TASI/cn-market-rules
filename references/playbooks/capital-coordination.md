# 组合资金联动：打新、逆回购、转债与REITs

核验2026-10-09。操作时点依据[IPO-SH、BSE-CASE、REPO、REPO-SETTLE](../sources.md)，日期由个案公告与券商确认提供。目的为现金压力研究，不自动安排交易。

## 先分清资金状态

| 状态 | 能否充当现金 |
|---|---|
| 可用现金 | 按券商业务资格可用于相应场内业务，需确认是否可缴款 |
| 可取现金 | 已可转出银行，但跨账户/渠道到账另查 |
| 冻结申购款 | 不能重复用于其他申购/缴款 |
| 待退款 | 尚未确认可用前不计确定流入 |
| 转债/股票/REITs市值 | 不是现金，出售成交和交收另建事件 |
| 保证金/融资额度 | 不是无条件现金，单独负债与追保情景 |

IPO底仓市值与打新缴款现金是两笔需求；北交所和REITs现金认购需考虑全部认购资金占用、未获配退款和确认日。转股把债券变股份，不创造现金；停牌事件仓位不假设可出售变现。

## 现金日历

每条事件：账户、业务、资金类型、时点、确定流入/支出、证据、是否情景。未确认的退款/出售按压力情景推迟或取消。不要只按日终净额：上午缴款与下午退款不能相抵，需保留时刻。

`余额_t=初始可用现金+累计已确认流入−累计支出`。

`缓冲缺口_t=max(0,最低现金缓冲−余额_t)`；若无缓冲则余额小于0才是现金不足。汇总多个账户时只有可及时转移的资金才合并，受限账户分别算。工具要求同一现金池、显式source字段，同一时刻先扣支出后计流入，避免虚构日内信用额度。

## 联动核对清单

1. IPO中签/其他缴款最早截止时刻与备用现金。
2. 北交所、REITs申购全部占用金额及确认退款可用时刻。
3. 逆回购到期清算、可用、交收和可取分别标注，名义期限与日历相符。
4. 转债最后交易/转股、股票到账与出售可执行性；转股卖股的隔夜价格情景。
5. 事件股份临时保管、连续持有/停牌及行权支付时点。
6. 多事件同日触发与退款延迟，最大缺口和持续时间。

## 虚构演示

初始可用20万元，保留缓冲2万元：周一9:00认购冻结10万元、周二9:00REITs认购8万元，现金余2万元；周二10:00IPO缴款1.5万元，缓冲缺口1.5万元。周二15:00才退款8万元，不能拿它覆盖10:00缓冲。对应[示例账本](../../examples/cash-ledger.json)可计算最高缺口。

基础情景、退款晚1—3交易日、无成交/行权失败、多个申购同时获配分别计算。增加资金来源只在来源可实现且提前到账时计入。对尚未到账款项作压力计算不代表事实违约。
