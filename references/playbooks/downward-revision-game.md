# 下修博弈

核验2026-10-09。规则依据与适用范围沿用所链接规则篇；以下为研究框架，不是监管规定或概率承诺。

依据[转债条款](../rules/cb-clause-rules.md)确认承诺期、计数、董事会提议和股东会。偿债/回售压力、股东持债与历史下修可解释动机，不证明概率或必然。

计算各有效限价的最大值，不把前20日均价单独等同“到底”。用实际成交均价，净资产/面值只在合同和适用规则规定时加入。股价低于净资产不必然无下修空间，取决于当前转股价与合同限价；即使有空间也未必足以推动转股。

情景：不提议；表决否决；有限下修；按全部下限修正；修正后股价继续下跌。每个情景重算转股价值与溢价，不保证债价上涨。大股东持债在回避表决制度下不直接等于控制通过。

原包的历史统计与具体收益数字未补齐原公告，发布版未将其作为已核事实。
