# 交付前常见误区

核验2026-10-09；研究风险清单，具体市场规则从链接原文核对。

| 误区 | 检查 |
|---|---|
| 每5000元配号＝深市5000元可申购 | 门槛与单位分别核 |
| 转股1张＝二级买入1张 | 买入、卖出零券、转股分别核 |
| 不强赎＝信用安全 | 承诺范围和兑付能力分开 |
| 净资产必然封死下修 | 个券限价＋当时转股价 |
| 股东会通过＝行权资格 | 登记、反对议案、持有、申报 |
| 30%＝全部强制全面要约 | 收购路径与豁免 |
| 要约T+3＝资金到账 | 申请、交收与券商到账 |
| 申报量比值＝收益比值 | 数量与损益率 |
| 摘帽申请＝交易所已批准 | 决定与实施公告 |
| 净利润转正＝一定摘帽 | 所有警示原因和审计 |
| 所有退市都有整理期 | 退市类别与例外 |
| REITs70‰或用总发售为分母 | 70%×扣战配后数量 |
| 募集失败立即退款 | 期限和实际可用 |
| 原始权益人持仓20%锁60月 | 占总发售20%的部分 |
| 周五一天期计3天 | 首次/到期交收差 |
| 节前最后一天零利息 | 不覆盖假期不等于零天 |
| 待退款/股票市值当可用现金 | 现金状态与证据 |
| 涨停参考价能成交 | 流动性与委托结果 |
