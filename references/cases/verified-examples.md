# 个案原文核验示范

核验日2026-10-09。以下真实材料仅证明该版本披露内容，不替代后续实施公告；行情、收益与概率未从这些材料推断。收益教学参数在[情景文件](../../examples/scenarios.json)中明确标为虚构。

## 1. 中国重工异议股东现金选择权

来源[CASH-CASE](../sources.md)：中信建投证券对中国船舶吸收合并中国重工审核问询回复的专项核查意见，2025年6月，交易所披露2025-06-20。PDF第47页（正文6-2-2-47）明确资格，47—49页说明股数上限及当时尚无法确定最终申报数量。

| 个案字段 | 原文核验结果 | 状态/边界 |
|---|---|---|
| 反对票 | 指定交易方案相关议案/各子议案、合并协议相关议案均投有效反对票 | 已核；不是随便一项反对票 |
| 持有 | 持续持有代表该反对权利的股份至实施日 | 已核；具体账户股份数仍需登记核对 |
| 申报 | 在规定时间内成功履行申报程序 | 已核；实施日及申报窗口要补后续公告 |
| 数量 | 文件说明仍持股统计未完全排除先卖后买，是理论上限 | 已核；不能当最终有效行权数量 |
| 生效/执行 | 当时仍需注册及确定实施安排 | 该时点事实；不能据此推断2026当前进度 |
| 收益/税费 | 本示范未取当日成交价或个案税费 | 未核，不输出实际收益 |

研究问题是“能否保留资格”，不是“股东会通过即可立即拿现金”。理论上限和实际成功行权严格分开。

## 2. 金科股份同时撤销两类风险警示

来源[ST-CASE](../sources.md)：金科地产集团股份有限公司公告2026-040号，2026-07-01披露，PDF第1—4页。

| 字段 | 原文结果 | 定位 |
|---|---|---|
| 原退市风险 | 2024年度经审计期末净资产为负 | PDF第2页 |
| 原其他风险 | 连续三年扣非前后净利润孰低为负，持续经营不确定性 | PDF第2页 |
| 撤销依据 | 年报及审计/专项说明，逐项自查并申请，交易所同意 | PDF第3—4页 |
| 停牌/复牌 | 2026-07-01停一天，2026-07-02复牌并撤销两类警示 | PDF第1、4页 |
| 简称 | *ST金科变金科股份，代码000656 | PDF第1—2页 |
| 该公告交易限制 | 撤销后日涨跌幅10% | PDF第1页；后续新交易规则另看生效日 |

这证明申请、交易所审核同意、实施日是三个不同事实。不可从披露的归母净利润转正单独推断摘帽，也不可用该案例推成所有ST的涨跌幅变化。

## 3. REITs备案条件与业务类型

来源[REITS-CASE](../sources.md)：东吴苏州工业园区产业园封闭式基础设施证券投资基金招募说明书更新2026年第1号，PDF第300页（正文296页）“基金备案条件”。

| 字段 | 原文结果 | 适用边界 |
|---|---|---|
| 产品身份 | 已于2021成立的封闭式基础设施基金 | 更新说明书不是2026新发行 |
| 备案条件 | 注册份额、至少2亿元/1000人、合规战配、扣战配后网下70% | 文中回述个案募集，联查现行第48条 |
| 场外流动性 | 场外份额需按规则转托管才能参加场内交易 | 不能当普通随时赎回基金 |
| 回拨/配售率 | 未在本示范核最终发售结果 | 待补最终公告，不推测获配 |

现行规则的“未达80%即失败”与本基金历史备案条件的文字要求需按业务时点解释，不能用老合同覆盖新项目，也不能把制度最低线当作必然实际发售规模。
