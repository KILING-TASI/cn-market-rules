# 方法卡：规则适用与执行证据分层

方法版本1.0；核验2026-10-09。解决的问题是：同一个数字或同一份新规则，为什么不能直接给所有主体、板块和历史日期同一个结论？本卡复用已有版本选择器、[证据规范](evidence-standard.md)、[退市衔接清单](rules/delisting-transitions.md)及[执行条款](cases/execution-terms.md)，不扩事件库、不新建审计或法律意见引擎。

## 数据与假设

每次核对记录证券身份、市场／板块、角色（公司、基金管理人、持有人、提供方等）、上市标准、业务路径、财务年度、判断日和知识截止日。来源分开记录发布者、文件版本、公开日、生效日／区间、条文定位、获取／核验状态；需要盘中历史判断时另核精确可得时刻。

主体和事实缺失保留null及影响，不推成“不适用”或False。没有登记的旧版本不是不存在；effective_until=null不是永久有效。不同主体的合同不能相互填补价格、行权资格或到账日期。金额和比例保留原单位、分母与比较符，不从市值生成可用现金。

## 核对算法与公式

1. **先分关系**：谁享有权利、谁有义务、谁能决定或审批？“可以申请”“应当披露”“交易所决定”“提供方付款”分别记录，不把申请权改写为履约结果。
2. **筛文件版本**：对已核版本v，匹配市场、板块、角色、资产及专题，检查公布日不晚于知识截止日，且`effective_from ≤ 判断日 < effective_until`；无终止日仅在核验覆盖内使用。零候选返回gap，多候选返回ambiguous，条款暂缓返回deferred，不默选最新。
3. **再筛条款条件**：检查上市标准、年度、主体例外和继续适用的过渡通知。版本selected仅表示步骤2通过；步骤3尚未自动化，不能把selected打印成“资格通过”。法规、交易所业务规则和合同的适用／冲突需具体核对，不能仅按来源标签作统一排序裁决。
4. **核个案执行**：预案／决议 → 批准及最后有效方案 → 登记与申报／签约 → 最终结果 → 过户及费用 → 实际可用现金。每步绑定自身证据，预计日期不能证明实际到账。
5. **才算条件情景**：例如`可收净现金 = 已核有效数量 × 已核执行价 − 实际应扣税费`。若数量、费用或到账未知，输出带明确假设的敏感性情景；不填实际现金账本。换股使用实际获记整数股，理论比例不代替零碎股处理结果。

此流程是研究核对方法，不是“所有条件布尔合取即可完成法律认定”的算法。不同路径可独立触发风险，存在例外、裁量或未取得文件时继续标缺口。

## 少量验收与失效条件

实际运行记录见[方法验收](../docs/method-validation.json)，沿用已有测试，不为本卡新增镜像测试。

| 验收 | 应得到的结果／能发现的错误 |
|---|---|
| 沪市REITs基础设施，2025-12-30与12-31 | 2022版→2025版；防止废止日仍选旧版或同日选两版 |
| 同一商业不动产，2025-12-30与12-31 | gap→2025版；防止把新版扩展的资产范围回填旧版 |
| 2026沪主板交易规则公布日与实施日、暂缓条款 | 公布后未实施不选；实施日普通选段可选，暂缓条款仍deferred；不能用整份生效打开全部功能 |
| 北交公司相同负利润、扣后收入4900万元 | 按2.1.3第一项上市需核10.3.1(一)；第二至四项上市不适用该第一项；负净资产、审计、重述等仍另查。人工核条款，不声称全公司安全 |
| 同为北交股票，60有效交易日市值均2.9亿元 | 第四项上市标准才核10.2.1(四)；其他标准不因该指标直接判退市，其他路径仍另核。人工核标准与排除日 |
| 财会〔2026〕11号，同日发布、不同企业 | 境内外同时上市等指定主体2027起、其他境内上市2029起、执行企业准则的非上市2030起；允许提前执行，必须读财报采用依据。不能用公布日替代执行年度 |

新实施通知、规则撤改、证券身份／上市标准不明、追溯重述、公开时点不足、特殊审批或付款变更会使原判断失效，须重新核对来源。以上是有限边界验收，不是全市场覆盖、真实回测或预测准确率。
