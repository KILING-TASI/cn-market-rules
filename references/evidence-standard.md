# 证据与适用范围

核验日期2026-10-09。每条结论同时保留：来源ID、文件标题、发布主体、版本/公布日、生效日、市场与板块、业务与投资者类别、条文或PDF页码、判断截止日、核验状态。

## 证据分层

| 层 | 用途 | 不可替代的内容 |
|---|---|---|
| 法律/部门规章 | 法定义务、程序 | 交易所业务细节与个案合同 |
| 交易所规则和实施通知 | 市场、板块、日期相关的操作约束 | 公司约定价格、起算日、资格 |
| 公司/基金原公告 | 个案条款与实施 | 其他证券的条款与未来价格 |
| 投教、券商解释 | 帮助理解与定位原文 | 当前有效规则和最终公告 |
| 研究假设 | 压力计算与情景 | 已核事实、概率证据 |

旧预案不能覆盖最新实施公告。法规中“可以”不写成“必须”；期限区分自然日、交易日、工作日以及当日具体时刻。生效日期与公布日期不一致时采用生效状态，征求意见稿不作为现行规则。

## 冲突处理

记录冲突双方的标题、版本、条文和适用对象；先排除历史版本、不同市场和不同业务。仍冲突时保留两种解释，不直接计算可执行收益。向发布主体或实际券商确认，取得回复后更新记录。REITs的70‰说法已与现行第45条及投教第20问对照，两个原文均为70%；没有找到可支持70‰的原文。

状态使用“原文核对”“仅检索线索”“个案待补”“假设”。取得文件哈希仅证明字节身份；下载、解析、理解和当前有效性是不同状态。PDF页码按从1开始的文件页计，另标正文印刷页；网页用条号。税务存在投资者身份及交易路径差异，未知时输出税前情景和税费敏感性，不把未经确认的税率填成实际扣缴。

## 维护

每次判断重新打开官方规则目录，检查新发布/废止/暂缓实施和衔接安排；重新取个案最新公告与时间轴。来源失效时保留旧URL与核验日期并标出不能复核，不将镜像或媒体摘要静默替换成原文。无需发布官方全文，台账和精确定位足以支持复核。
