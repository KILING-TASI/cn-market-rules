# 离线计算说明

`scripts/scenarios.py` 使用标准库与Decimal。所有示例为虚构教学参数；不连接数据，不执行交易。数值不足时失败，不静默用零补齐。人民币金额输出保留两位，比例保留六位，内部计算保持精度。

| mode | 输入/输出 |
|---|---|
| dilution | 剩余本金元、原/拟下修价、同日当前股本、归母利润、股价、显式转股比例；比较总潜在与下修增量摊薄，正/零/负利润分开；可选利润调整未知留空 |
| tender | 股数、成本、要约价、收购率、余股退出价、费用、占用期/资金率；给净损益和盈亏平衡余股价 |
| merger | 股数、成本、换股比率、实际获记整数股actual_converted_shares、存续方退出价、尾款、费用、占用；比率给理论参考，损益用实际整数股与尾款，避免重复计算零碎股 |
| exit | ST/重组/现金选择权的退出情景；输入有效退出数量/现金与剩余资产价值，不判断资格 |
| reits | 沪深首发注册/最终份额、战配、网下、资金、人数、原始权益人是否合规参与和其他失败项；返回对应市场来源及五类失败检查与网下比例 |
| reits_expansion | 当前仅沪市；持有人大会批准量与实际认购、三条发售路径、明确净资产调整/合规费用及持仓认购；失败/路径违规时不输出发行后结构，定价/资格另核 |
| reits_return | 认购金额与价、情景获配率、退出价、分配、费用、加权资金占用（元×自然日）；返回获配份额、损益与两种分母收益率 |
| repo | 名义到期清算与下次交收按显式完整交易日历推算；输出四个日期、计息及净利息 |
| cash | 同一现金池事件按时刻排序、同刻支出优先；返回余额轨迹、最低余额和缓冲缺口 |
| clause | 按输入日期、价格、当期转股价、窗口/阈值/比较符判命中；连续计数和窗口命中分开 |

机会成本=`投入资金×年化机会成本率×自然日/365`；利率输入小数（0.03=3%），不是百分数数值3。机会成本与净利息分开；收费总额由使用者核对。没有概率输入及期望收益，避免无依据概率。

REITs边界：首发工具支持SSE/SZSE五项检查，数量统一份额，比例分母为最终发售量减战配；未知boolean不能当False。首发mode仍拒绝扩募。扩募只支持沪市已核路径，见[独立规则](rules/reits-expansion-rules.md)，未知资产调整不能默认0，只有明确教学假设可输入0。未覆盖特殊法律例外，不替代管理人正式结果公告。

回购日历：`first_settlement=成交日后的下一交易日`；`maturity_clearing=不早于成交日+名义自然日期限的第一个交易日`；`final_settlement=maturity_clearing后的下一交易日`；`计息天数=final_settlement−first_settlement`。这是通常交收模型，实际账务异常单独核对。`calendar_source`、`calendar_start`、`calendar_end`须显式填写，整个覆盖区间内全部交易日由使用者保证；工具拒绝范围外推算，但无法证明日历输入没有漏日。

交易条款计数：dates、prices、conversion_prices须同长且日期唯一递增，价格与转股价正数；不接收缺失日，不自动填停牌或除权。日期数组应包含本条款计数区间全部有效交易日。比较符支持lt/le/gt/ge；window命中不代表未来触发日期可确定。ST低价示范可以把conversion_prices设为1、threshold设为1、lt比较，仍要另核条款的排除日与市场。

现金模型：负余额和缓冲不足分开输出；流入证据需要source，可取/融资/待退款不得混入可用现金账本。跨账户调拨需另做成可实现流出/流入事件。示例的source注明“假设”，不会伪装实际到账。

v2.1支持`--calendar calendars/2026-SSE.json`或SZSE，见[日历说明](../calendars/README.md)。只对repo案例注入，原有内嵌数组兼容；任意已内嵌日历字段与外部文件并用报错。2026计划日历不包含2027交收日，不能保证年末所有期限可算。示例的validation_calendar仅用于包校验，实际命令仍显式传--calendar。
