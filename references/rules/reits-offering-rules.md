# 公募REITs发售规则库

核验2026-10-09。主规则范围：上交所现行首发业务，2025-12-31生效的不动产REITs业务办法/发售指引；办理文件另查2026-06指南。依据[REITS-BASE、REITS-SALE、REITS-GUIDE、REITS-EDU、REITS-CSRC、REITS-SZ-SALE](../sources.md)。已取得深交所现行发售指引附件并核对第21、45、48条关键条款；扩募与其它深市细节另核，不能默认全部相同。

## 回拨的单位与分母

第45条原文单位为**70%**，不是70‰；投教手册第20问同样如此。设总发售Q，战配S，扣战配后F=Q-S，回拨后网下N：`N/F≥0.70`。对应公众最多0.30F仅是该数量限制下的上限，不是固定公众发售量。

公众不足可以回拨网下；网下认购低于最低数量不能向公众回拨。网下充足且公众认购倍数高时，可以从网下回拨公众，但不能突破前述下限。是否启动、倍数触发、数量及公布时点按发售公告，不把某项目100倍/10%写为统一规定。

深市现行发售指引第45条（PDF第13—14页）同样为扣战配后70%，第21条为不同报价不超过3个、最后整组提交有效，第48条（PDF第14—15页）同样列五类失败情形。v2.1已逐项核对初始发售失败检查并支持market=SZSE；对应来源ID随结果返回。工具覆盖这五项算术，不等于核定所有业务资格。

## 沪深首发条款对照

| 项 | 沪市 | 深市 | 边界 |
|---|---|---|---|
| 定价/询价 | 办法22条，发售指引21条 | 办法22条，发售指引21条 | 网下询价、3种不同价、最后整组报价；非公众报价权限 |
| 网下主体与注册 | 发售16—17条 | 发售16—17条 | 利益冲突主体排除与列明例外、询价前1交易日12:00注册；还要当次公告审核 |
| 原始权益人战配 | 办法21条，20%/60月、超出36月 | 办法21条，同数值与持有期禁质押 | 多原始权益人条件文字不同，不能只核合计比例 |
| 多主体特别要求 | 控股/实际控制及同控关联方原则上单独适用前款 | 多原始权益人时控股/实际控制原始权益人等60月份额原则上≥总发售20% | 保留各市场原文，具体股权结构核对 |
| 配售/确认 | 发售37—43、46—47条 | 发售37—43、46—47条 | 有效报价、缴款、关联账户限制、限售、最终公告；公众配售非保证获配 |
| 回拨/失败 | 发售45/48条 | 发售45/48条 | 两市五类失败和70%分母一致；项目额外条件仍需输入 |

深市依据[REITS-SZ、REITS-SZ-SALE](../sources.md)现行附件，原始权益人特别约束不简化成“两市完全一样”。交易/转托管、商业试点其它差异另读，不声称全部细则完成。扩募另见[独立扩募规则](reits-expansion-rules.md)。

例：Q=1亿份、S=3000万份，则F=7000万份，N至少4900万份；不是700万份，更不是以Q为分母的7000万份。计算输入统一用小数0.70表达70%，文档同时显示分子/分母。

## 募集失败：四类常见红线＋其他情形

依据现行第48条，检查以下各项，任一触及即存在募集失败条件：

| 项 | 判断 |
|---|---|
| 份额 | 最终总额未达到准予注册规模的80% |
| 规模或人数 | 资金不足2亿元，或者投资人少于1000人 |
| 战配 | 原始权益人或同一控制关联方未按规定参与 |
| 网下 | 扣除战配后网下发售比例低于70% |
| 其他 | 法规、公告或事实导致的其他失败情形 |

80%、2亿元、1000人、70%等恰好边界与“低于”区分。失败后30日内返还款项并加银行同期存款利息，不能说失败立即退款；中止发售与募集期满失败不同，询价量不足的中止见第22条。扩募看独立指引，不用这里的首发工具直接决定。

## 战略配售分层

原始权益人/同控制关联方持有总发售至少20%；**占总发售20%的那部分**至少锁60个月，超出部分至少36个月，不是把该主体持仓的20%锁60个月。对该主体相应条款明确持有期间不得质押。其他专业机构战投基础设施REITs一般至少12个月，依据REITS-CSRC第18条；更长承诺、特殊主体、商业不动产试点及扩募条款逐项目核对，不能自动推广所有战投都适用同一禁质押句。

锁定自上市起算，未获份额不计；原始权益人参与可有监管认可的其他对价，不能只凭“现金缴款少”认定未参与。配售协议、招募说明书、合同生效及上市公告四者对照；网下也可能约定限售比例，公众场外份额转托管有时间成本。

## 询价

第21条：同一网下投资者全部报价中的不同价格不超过3个；可多次提交，以最后一次提交的完整报价记录为准。不是每个配售对象各自再享有3档。注册、资格审核、有效报价、认购义务、认购资金及费用读第17、23—24、37—42条与发行公告。

公众认购不用IPO门票市值。场内/场外账户、适当性和风险揭示另查第6、8—9条。场内份额可参与场内交易，场外需转托管；封闭式基金不假设可随时向管理人赎回。

## 个案核对与情景

| 字段 | 原文与计算 |
|---|---|
| 版本/业务 | 交易所、首发/扩募、基础设施/商业不动产 |
| 发售规模 | 注册份额、认购价、战略/网下/公众初始与最终数量 |
| 回拨 | 条件、是否触发、扣战配分母、最终配售率 |
| 资金 | 认购费用、退款/确认/上市/转托管日期 |
| 锁定 | 主体、20%分层、锁期、禁质押及自愿加长承诺 |
| 失败 | 五项逐项检查、退款利息与最晚期限 |
| 收益 | 获配份额×退出价＋分配−成本−费用−机会成本 |

情景至少列未获配、上市上涨、上市折价、募集失败/退款延迟；分配收益率不等于价格总收益率。公众配售率分母用最终有效公众认购，不能用全部基金认购混算。详见[情景计算](../calculations.md)和[组合现金联动](../playbooks/capital-coordination.md)。
