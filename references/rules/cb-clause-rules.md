# 可转债条款：强赎、下修、回售

> 许可范围：本文件涉及原包专题或提供方案的改建来源，不声明整文件 MIT。见[第三方与未明来源](../../THIRD_PARTY_NOTICES.md)。原材料未经许可的表达不纳入根许可证。

核验2026-10-09。部门规章依据[CB-BASE](../sources.md)第8—15条；以公开发行可转债为主要研究范围。向特定对象发行可转债的转让、锁定与下修不同，不能套公开发行模型。

## 条款与法规分开

第8条规定发行结束不少于6个月后方可转股，个券转股起止日读募集说明书。第10条要求下修经股东会出席表决权2/3以上同意，持债股东回避，价格不得低于会前20日和前1日股票交易均价。**净资产/股票面值等额外下限是否存在、用哪一期净资产，逐券读取**；本库不把净资产下限说成当前部门规章对所有转债的统一要求。

15/30日、130%、余额不足3000万元等为常见强赎合同参数；低价阈值、观察周期、计数是否连续和起算区间同样是个券参数。规章关于未转股余额少于3000万元的信息披露，不等于所有个券同额强赎条款。向特定对象发行的转股价格不得向下修正，见第9条。

## 可核验条款表

| 项目 | 必填个案参数 | 结果 |
|---|---|---|
| 价格强赎 | 观察窗口W、命中日数K、比例a、≥/＞、转股期起点 | 窗内命中、尚差日数、最早可能日（条件预测） |
| 余额强赎 | 合同金额、是否独立路径、判断日余额 | 合同条件是否满足 |
| 不赎回承诺 | 起止日、价格/余额路径范围、重新计数规则 | 未覆盖路径仍核查 |
| 下修触发 | W/K/a、严格不等号、起算区间、承诺期 | 公司有提议权，不代表必提议 |
| 下修下限 | 会前20日均价、前1日均价、个券净资产/面值及其他约束 | 全部有效下限取最大值 |
| 有条件回售 | 适用计息年度、连续或累计日、比例、年度一次/重置机制 | 资格与触发分开 |
| 附加回售 | 募资用途变更、申报期、价格、税费 | 与低价回售分开 |
| 执行时限 | 最后交易、最后转股、登记、赎回/回售、到账日 | 用公告精确日期 |

`下修下限=max(会前20日交易均价,前1日交易均价,合同中适用的其他价格下限)`。均价按成交额/成交量及公告口径，不用收盘价平均代替。当前转股价低于约束下限时不能凭净资产比率判断空间。

## 计数与时间

价格调整日前后按当日有效转股价分段比较。下修导致回售计数重置、不下修承诺结束后重新计数等必须有个券/适用规则依据。滚动窗口中旧命中会移出，因此“还差K-hit日”不是无条件触发倒计时。

“连续30日低于70%、最后两个计息年度、每年一次”只作常见条款识别词，未取得募集说明书不直接确认。普通价格调整与向下修正不同，不能用一次下修逻辑覆盖所有价格调整。

强赎触发不等于执行；赎回金额从公告核对，不能默认只在100—100.9元区间。不赎回承诺不消除信用和市价风险。转股成为股东、股票可卖及现金尾款到账分别核对；[交易边界](trading-rules.md)与[强赎操作风险](../pitfalls/redemption-traps.md)配套使用。
