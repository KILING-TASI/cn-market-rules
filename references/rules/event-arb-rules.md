## 要约收购

第23—25条区分自愿全面/部分要约，以及证券交易达到30%继续增持的要约路径。协议收购读第47条及第六章豁免；不得只看30%就判定必须全面要约。全面/部分是收购范围，与法定/自愿是不同维度。

| 核对项 | 原文定位 | 研究要点 |
|---|---|---|
| 预定数量 | 第25条及报告书 | 一般预定比例下限5%，个案数量绑定股本口径 |
| 价格 | 第35条 | 六个月取得价和30交易日均价说明分开 |
| 履约安排 | 第36条 | 保证金、银行保函、财顾连带保证等安排逐案确认 |
| 期限及变更 | 第37、39、40条 | 30—60自然日一般期限；竞争要约例外；不得降价、减数量、缩期限 |
| 预受/撤回 | 第42条 | 临时保管不得转让，最后三交易日撤回受限 |
| 超额预受 | 第43条 | 部分要约按同等比例收购，零碎股处理另查 |
| 结算 | 第43条 | 期满后三交易日内办理申请，实际过户/款项到账从结果与券商核对 |
| 上市条件 | 第44条 | 按股权分布判断及剩余股东出售安排，不硬编码75%/90%两条线 |

`预计收购率=min(1,预定收购数量/最终有效预受数量)`。日度预受量不是最终量，只能做敏感性参数。要约价高于市价也不保证整笔获收购、更不保证扣除余股风险后盈利。

## 换股吸收合并

`每股换股参考价值=换股比例×存续方参考市价`，价格时点一致并考虑除权除息、零碎股现金处理、停牌及新股可交易日。不是锁定兑付价。识别存续方收购请求权与被合并方现金选择权，不能混淆主体。

异议股东资格以方案和实施公告为准。中国重工已核案例要求指定议案/子议案有效反对票、持续持有对应股份至实施日、按时成功申报；股东会通过或临近行权才买入不能替代资格。中途部分卖出、买回和净卖出数量的认定另查，不笼统断言所有剩余股份都失权。

| 个案字段 | 必须取得 |
|---|---|
| 资格 | 登记日、指定议案、反对票股份、持续持有算法、排除主体 |
| 价格 | 最终行权价、除息调整、主动调价触发/权限/期限 |
| 行权 | 申报日期与时刻、系统/手工、资料、撤回规则、有效确认 |
| 退出 | 支付日期、过户、新股份登记/交易、未行权处理 |
| 税务 | 投资者身份、现金出售/换股/尾款类型、收费及代扣依据 |

行权价低于市价可能造成经济损失；也要与成本比较，行权价低于市价与低于买入成本不是同一结论。停牌意味着无法市价退出，账户显示市值不是可用现金。比较行权净现金、可实现市场卖出、换股价值三种路径。

## 重大资产重组窗口

把预案、董事会、股东会、交易所审核/证监会注册、其他审批、交割、停复牌分成事实节点；每个方案适用的审批不相同。复牌连续涨停属于市场结果，不能用规则预测。“破发”需明确相对发行价、换股价格或其他基准，重组股票未必存在可比IPO发行价。

至少算：完成且价格符合假设、完成但延迟/价差压缩、失败后退出折价。涨跌幅上限不是实际成交价，连续涨停/跌停也不证明可成交。见[收益模板](../../templates/scenario-analysis.md)和[失败风险](../pitfalls/event-arb-failures.md)。
