# ST摘帽与退市：先识别原因，再核对撤销

核验2026-10-09。数值及条号主要覆盖沪深主板2026版；依据[ST-SH、ST-SZ、TRADE-SH、ST-CASE](../sources.md)。科创/创业/北交所不能直接套主板收入门槛，已列独立规则入口，未完成全板块指标对照。

## 风险警示不是盈利标记

ST表示其他风险警示，*ST表示退市风险警示；可能多项原因叠加。撤销一个原因不一定撤掉全部风险警示，*ST可能变ST；公司申请不等于交易所同意，交易所决定不等于立即恢复交易。识别财务、规范、交易、重大违法、主动退市路径。

| 财务撤销 | 9.3.7—9.3.10 | 9.3.8—9.3.10 | 次年度报告及终止上市排除项、申请/审批 |
| 规范类 | 9.4节 | 9.4节 | 披露、内控、资金占用等问题是否按期限整改 |
| 重大违法 | 9.5节 | 9.5节 | 正式行政处罚/司法事实、重大违法适用条款 |
| 交易类 | 9.2.1 | 9.2.1 | 价格、市值、交易量、股东数量与连续日数 |
| 其他风险警示撤销 | 9.8节 | 9.8节 | 原因对应的专项文件与时间条件 |

主板财务研究注意：利润总额、净利润、扣非净利润孰低为负且收入低于3亿元的组合条件，与负净资产、无法表示/否定审计等独立条件分别判断；按规则剔除无商业实质收入，不能把利润总额/归母净利润中任意一个转正当作摘帽成立。警示后次年度退市判定和撤销审计条件可能更严格，不能只查首年警示条件。

沪主板仅A股示范：连续20交易日收盘价均低于1元、连续20日总市值均低于5亿元等为不同交易类指标；恰好1元不计“低于1元”。价格日数为连续而非30日累计，全天停牌不计入规定交易日。成交量、股东人数、B股及存托凭证另有条款。本库计算只输出条款输入下的连续计数，不自动作法律终止上市认定。

## 撤销清单

| 核对项 | 个案证据 |
|---|---|
| 原因完整 | 原实施公告全部条款及后续新增警示 |
| 财务纠正 | 年报、财报审计、扣收专项、内控审计、追溯重述 |
| 其他风险消除 | 占用清偿、担保解除、账户解冻、持续经营、处罚及诉讼预计负债等对应文件 |
| 申请与受理 | 提交日、补件、问询及回复、是否符合期限 |
| 决定与实施 | 交易所同意、公司公告、停复牌、简称、涨跌幅生效日 |
| 仍有退市风险 | 未撤销情形、重大违法、低价计数及未来期限 |

两主板财务路径有年报披露后五交易日申请和完备材料后十五交易日决定等程序；补件/调查可能影响期限，逐市场具体条款核对，不作为资金回流的保证日期。

## 退市与现金风险

交易类强制退市不提供普通退市整理期；非交易类一般整理15交易日，但重整、已筹划重组等存在不进入整理期安排。主动退市另有流程。不能假设任何退市都有15日逃生机会。退市整理首日、后续涨跌幅及买入权限由交易规则/板块决定，不把转债20%限制套普通主板股票。

重大重组或破产重整并不当然中止退市指标；股票退市也不等于股东全部资产自动归零或债务自动消失，但转板转让、回收金额和日期均不确定。情景给出获批摘帽、维持警示、延迟、退市折价/无法退出，不把股票账面市值作为可支配现金。

已核金科示范见[个案核验](../cases/verified-examples.md)：正式公告明确同时撤销两类警示和停复牌日期，不凭公司“申请摘帽”新闻认定完成。
