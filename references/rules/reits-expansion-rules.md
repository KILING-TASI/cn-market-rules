# REITs扩募：路径与失败检查独立建模

核验2026-10-09，模型覆盖独立取得的沪市[REITS-EXP-SH](../sources.md)与深市[REITS-EXP-SZ](../sources.md)现行指引，均2025-12-31施行。以下第36—50、52条在两市原文逐项比对，不能仅因编号相同假定规则通用。

| 路径 | 定价与权利定位 | 关键额外核对 |
|---|---|---|
| 原持有人配售 | 第41—43条：登记在册、同配售比例、按市场/项目价值合理定价 | 大持有人/原始权益人等承诺履行，原持有人认购是否达到拟配售80% |
| 公开扩募 | 第44—45条：可全部/部分优先配售；发售价不低于公告前20日或前1日交易均价 | 公告具体选择基准、优先比例与余额认购 |
| 定向扩募 | 第46—50条：发售对象一般不超过35；价格不低于基准前20日均价90% | 产品合并计数、定价基准特殊条件、一般6月/特定18月限售 |

第40条以**持有人大会表决通过规模**为80%分母，不沿用旧版“准予注册规模”的措辞。另查原始权益人等按规定参与战配、其他失败条件。失败30日内退款并加银行同期利息，非即时可用。第37条战略对象原则上限拟购项目原始权益人及同控制关联方，份额比例与持有期限参照首发，监管例外另核。

`reits_expansion`显式指定SSE／SZSE，深市必须填rule_applicability_date，范围为2025-12-31至核验截止2026-10-09，历史旧版与未来不外推。区分三路径：一般80%/战配/其它失败检查；原持有人路径追加承诺和原持有人认购80%；定向追加35对象上限。定价下限、资格与审批仅提示另核，不自动认证；输入应按公告口径完成对象合并计数。

初始基金的2亿元/1000人/扣战配网下70%不能机械移植。中止、失败、备案/批准与最终发行分别记录。工具检测失败或路径违规时不输出“发行后的”资本结构。

通过输入检查后的资本结构为条件情景：原净资产＋融资现金−可由基金承担的发行费用＋明确净资产调整，再除以总份额。净资产调整包括项目买入/公允价值/负债及现金使用的净影响；不得同时重复计融资款与新资产全值。第52条禁止从基金财产列支列举的购入项目评估、财顾、会计、律师费用；`permitted_issue_fees`只填有依据允许承担的费用，不借模型绕过规则。

原持有人必须填原持仓和实际认购；不参与的持股比例下降与每份净值变化分别输出。发行价折价不等于经济损失，新资产回报、融资与费用需要单独论证。示例见[扩募情景](../../examples/expansion.json)。

## 两市独立原文对照与深市执行条款

| 核对项 | 沪市依据 | 深市依据与适用边界 |
|---|---|---|
| 三路径及战略对象 | 36—37条 | 36—37条，PDF14页；原战略持有人认购可视为原持有人配售，必须按公告核总量，不能重复计战配和持有人认购 |
| 一般失败80%及30日退款 | 40条 | 40条，PDF15页；分母均为持有人大会通过规模，80%恰好通过，退款加同期存款利息是期限约束而非已到账 |
| 原持有人承诺与80% | 41—43条 | 41—43条，PDF15—16页；20%以上第一大持有人的口径按54条合并关联方／一致行动人，同登记日、同配售比例 |
| 公开扩募价格 | 44—45条 | 44—45条，PDF16页；公告选20日或前1日均价，不用收盘价替代交易均价 |
| 定向对象35名／90%／基准日 | 46—49条 | 46—49条，PDF17—18页；指定管理机构两只以上产品合并计一名；基准日一般发售期首日，特殊预先定对象须满足48条 |
| 定向限售 | 50条 | 50条，PDF18页；上市起6个月，48条第二款对象18个月。战略配售另按37条首发持有要求逐项核，不默认仅6／18个月 |
| 新购项目费用 | 52条 | 52条，PDF19页；评估、财顾、会计、律师等购入费用不得列基金财产，不等同所有发行费用可扣 |
| 执行披露 | 以沪市原文核 | 深市26—29条，PDF10—12页：实施完毕3工作日内实施报告；非定向发售首日3日前招募说明书；定向验资完2工作日内发行情况；上市3工作日前交易公告 |

以上共同核得的失败检查和资本结构算术复用同一实现，输出仍绑定各自source_id；资格、价格下限、对象合并计数及锁定期未由算术自动认证。深市34—35、38条的筹划／发售停复牌分别核对，不能假设所有扩募都全程不停牌。原始权益人合规参与和“其他失败情形”必须显式输入，unknown不能默认为通过。
