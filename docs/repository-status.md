## 职责与独立运行

核心负责规则原文定位、有限版本目录、市场常规交易日历、个案条款证据和给定条件的算术情景。上游是监管机关、交易所、发行人及用户显式参数；下游按已声明契约消费规则选择、证据和缺口。Python 3.10+ 标准库即可独立运行 README 的命令，无账户、联网或工作台安装要求。人工取得原文不构成自动更新服务。

公司经营、研究组织与综合判断归研究工作台；规则库不扩事件平台。财报库不承担估值审计平台，穿透库不承担基金全评价，MarketLens 不承担全部公司事件库；这些是协作职责约定，本页没有核验其实现。共用底座不归本库维护。

时间语义：观察、事件、公布、生效／失效、取得、核验和历史公开可得时间分别保留。已有记录多为日精度、按中国 UTC+08:00 日界线；没有时分秒就不能推定盘前可得。retrieved_at 是取得日，source-retrieval.json 的 checked_at 是检查记录日，不能提升为历史可得时间；无证明的首次公开时刻、available_at、原版本摘要和解析器版本明确未登记。规则查询 knowledge_date 是知识截止条件，不是所有来源的可得证明。日历 JSON 没有独立取得日／快照摘要，不以 verified_at 填补；原通知定位见 calendars/2026-holiday-notice.md。

原页找到、下载成功、原文语义核验是不同证据，来源台账与下载日志不强行一对一合并。原文 PDF／DOCX 和私有资料不发布；公开可读不等于再分发授权。数据权利独立于原创 MIT，第三方许可保留，未知权利按 LICENSE_SCOPE.json 和 THIRD_PARTY_NOTICES.md 的限制处理。

## 契约差异、复用与反例

最小适配复用 `scripts/common_interface.py`，不增加另一套公共记录或状态枚举。公告样本 identity-partial 已有原输入与交接结果：30000000 shares、ratio 字符串0.5096、分母日期、null 合同价格与身份缺口保留；schema1.1→交接1.0可无损回转。规则模板 schema1.2→交接1.0的 selected／gap 已完成工作台实际消费，证据见[联合回执](workbench-integration-validation.json)。这不是九仓同样本验收；公告真实样本跨仓消费、日历跨仓复用及另两条链尚未验证。

原发布者 publisher 与获取 URL 已分开；获取渠道域名不替换发布者。接口库版本、原始字节快照摘要、解析方法版本、时间精度等尚无统一顶层字段；保留已有专业字段及 legacy_payload，未提供时维持未知，不按字段同名强行映射。日历没有证据信封适配，仍走原入口；不得把派生日期数组强制包装成已核行情事实。冻结预览内重复来源／目录片段是当时快照，common-inputs 与 common-examples 是输入／派生适配对照，均不是第二套可独立更新主台账。新取得同一原件时可复用原始快照，但新解释与新查询另存，不覆盖旧事实。

反例：将 gap 改成 selected 会拒绝回转；消费者不支持schema1.3／交接1.1时明确拒绝；2027交收不外推；不把取得日当公告首次可得日，不把解除与再质押相加为净新增，不把未取聚合数据填0或换官方口径兜底。
