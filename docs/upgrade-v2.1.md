## 设计修正

| 原设计问题 | 本次决定 |
|---|---|
| 下修后总摊薄混同下修额外影响 | 同样的剩余本金和转股比例，对比旧/新转股价；输出额外股数、持股比例变化与两种EPS |
| outstanding_units易被当张数 | 改用outstanding_principal，明确单位元；张数输入先按面额转换 |
| 已转股股数未进入公式 | 删除该字段；existing_shares是同一截止日现有总股本，已含此前转股，剩余本金不含已转股债 |
| 默认全部转股或缺值填零 | conversion_fraction显式输入；利息节约/经营变化未知时调整EPS留空，静态EPS单独标假设 |
| 亏损公司也输出“EPS摊薄” | 正利润给EPS压缩比例；零利润不可相除；负利润给每股亏损绝对值变化，均不等于股东损失 |
| 案例只用最终公告/禁止约数 | 合同、募集说明书、正式阶段公告、受托报告均可；结论必须限定材料时点，保留原文约数精度 |
| 所有板块统一第9章 | 每版核对：科创第12章、创业与北交所第10章，主板第9章；过渡、特殊上市标准与独立路径分开 |
| 日历只给当年却声称覆盖全年回购 | 覆盖为交易日期范围，不保证全部期限均可计算；跨年缺下一交收日时报错，2027未发布不猜 |
| 扩募视为份额摊薄小功能 | 分原持有人配售/公开/定向；失败检查与资本结构算术分开，新资产及费用变化显式输入 |
| 无LICENSE即任何使用违法 | 不作统一法律判断；自有内容授权、输入材料权利与平台权限区分。本次不替用户选择许可证 |

## A：下修模型契约

mode=dilution。必需字段：outstanding_principal（元、正整数）、old_conversion_price/new_conversion_price（元/股，0<新<旧）、existing_shares（同截止日总股本、正整数）、net_profit_ttm（元，可负）、underlying_price（元/股，正）、conversion_fraction（0—1，显式情景比例）。可选profit_adjustment（转股后年化归母利润净变化，元，包含利息节约/税/经营变化的情景，不知道就不传）。

P=剩余本金，f=情景转股比例，S=现有股本，c0/c1=旧/新转股价，N=同口径利润：

- 旧/新理论增股=P×f/c0、P×f/c1；额外增股=两者差。
- 旧/新潜在摊薄=增股/(S+增股)；额外变化以比例差表示（×100才是百分点）。
- 当前、旧价转股后、新价转股后静态每股利润=N/S、N/(S+旧增股)、N/(S+新增股)。
- 正利润EPS压缩=1−新EPS/旧EPS；零利润返回null；负利润仅给每股亏损绝对值变化。
- 转股价值按100元面额比较，参考股价保持不变；新价值/旧价值−1。
- profit_adjustment存在时另算(N+调整)/(S+新增股)，不覆盖静态结果。

理论增股不做逐账户整数分配，EPS为同口径静态示范，不是会计准则加权平均股本EPS预测；未校验限价合法性、权益价值变化、转股执行能力或公司下修意愿。摊薄比例不是损失率。

## 案例补证契约

每条记证券身份、事件时点、材料角色（合同/阶段/实施/结果/受托进展）、精确来源、字段值、可迁移检查点及不能推广范围。只有完整搜查证据才可写“原文未约定”；没取得文件写“未知”。

代表性补证成功即可交付该批；其它案例保留已查范围和缺口，不重复无界搜索。不得用终止上市推断已违约，不能用兑付金额推断投资者真实成本与亏损率。以后取得结果公告再补最终兑付状态，不把历史阶段事实冒充当前状态。

## B：退市指标契约

数值表区分首年财务警示与警示后次年终止；利润孰低与扣收组合不拆成独立收入门槛。交易类面值/市值/交易量/股东数分别是独立路径，连续交易日、停牌排除、上市未盈利豁免及研发型企业另列。规范和重大违法以条款路径为主，不以一张简表声称覆盖所有例外。

## C：REITs契约

首发SSE/SZSE分别关联已核法律文本。扩募先取得现行第3号指引及第2号发售扩募章，分别记录原持有人配售、公开、定向；份额80%、原始权益人战配、承诺履行及原持有人80%认购等适用条件不能混为首发2亿元/1000人/70%检查。

资本结构算术：总份额=既有+实际新增；老持有人明确原持仓和实际认购，不用一个holder_priority_ratio猜持仓。后净资产=原净资产+认购融资−发行费用+净资产调整，新增资产获取、负债及交易价格与公允价值差异进入调整；不把扩募价低于净值直接认定损失。失败检查与估值输出独立，不自动确认正式募集结果。

## D：日历契约

calendars内日历带market、来源ID/URL、公布日、核验日、覆盖起止和完整交易日。按交易所休市通知及周末生成，调休工作周末仍休市；不是港股通或基金申赎日历，也不保证交收异常不存在。

--calendar只注入repo案例，非repo案例照常计算。内嵌trading_days和外部日历同时提供报错；来源/覆盖冲突报错；market给出时要求匹配。跨年超范围、2027文件缺失明确报错，禁止推测。保留原有内嵌数组兼容性。
